# もくもく問題集

クラウド資格(AWS など)の学習用に、問題を解き、間違いを復習できる Web アプリです。開発中です。

## 状態

小さな段階(v0.0.1 → v0.1.0 → …)に分けて作っています。各段階の内容は、`data/release-notes.json` と
GitHub の Issue で確認できます。

## 開発の始め方

必要なもの: Node.js 22 以上

```sh
npm install   # 検査フック(.githooks)も有効になります
npm test      # 検査ロジックのテスト
```

環境固有の値(プロファイル名・ドメインなど)は、`.env.example` をコピーした `.env`(gitignore 済み)に書きます。
リポジトリには、実値を書きません。

## 開発の進め方

ブランチ名、コミット、PR、検査の流れは、[CLAUDE.md](./CLAUDE.md) に書いています。
