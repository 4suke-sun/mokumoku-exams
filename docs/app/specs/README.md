# 画面の仕様

新しいモードや画面の仕様を置く場所です。書き方と承認の流れは、[画面の仕様のひな形](../../ui-spec-template.md)にあります。

## 置くもの

- 実装の前に承認を得た、画面またはモードごとの仕様(1 つの画面・モードに 1 ファイル)。
- 小さな仕様は、Issue の本文に書いてよく、ここには置きません。

## ファイル名

- `<画面またはモードの名前>.md`。英小文字とハイフンだけにします(例: `learning-mode.md`)。
- 名前は、画面やモードが実装で使う名前に合わせます。

## 保つこと

- 承認のあとに作りが変わったときは、仕様を直します。実装と食い違ったままにしません。
- 仕様の内容は、デザイン方針・データの仕様・ADR を書き写さず、参照します。
