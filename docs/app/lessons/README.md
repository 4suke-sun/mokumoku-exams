# 学び(lessons)

失敗とその対処を、あとで再利用できる形で残します。**一般的な注意書きの形**で書きます。

## 置き場と名前

- 置き場は `docs/app/lessons/` で、1 件につき 1 ファイルです。
- ファイル名は `NNNN-<短い英語の説明>.md`(例: `0001-test-dummy-values-concat.md`)。番号は 4 桁の連番で、重複させません。
- 一覧は、下の自動生成の部分に載ります。`npm run check:lessons -- --write` で更新します。

## 書式

```markdown
# 題(注意することを、短く)

## 注意すること

規則を、現在形の一般的な書き方で書く。

## 理由

その規則が必要な理由。

## 対処

どうすればよいか。必要なら、短い例を添える。
```

- 3 つの見出し(`注意すること`、`理由`、`対処`)は、この順で、すべて必要です。
- 出来事を語る書き方にしません。「〜してしまった」「実際に発生した」「先日」「その際」のような、いつ・だれに起きたかを語る言い方は使いません。「〜すると、〜になる」「〜する」のように、規則として書きます。
- 環境固有の値、個人情報、認証情報は書きません。説明に必要な値は、プレースホルダーにします。

## 検査

`npm run check:lessons` が、ファイル名、見出し、出来事を語る書き方、機密らしい内容、一覧の更新漏れを検査します。CI でも実行されます。

- 出来事を語る書き方の検査は、特定の語を並べたものです。完全ではないので、書いたあとに、規則として読めるかを、人の目でも確かめます。
- 検査に止められた語は、言い換えます(例: 「以前の版」は「旧い版」、「その際」は「このとき」ではなく、条件で書く)。
