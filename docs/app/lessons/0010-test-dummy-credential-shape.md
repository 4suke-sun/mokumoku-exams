# テストのダミーは、認証情報や ID の形に見えない中立の値にする

## 注意すること

値を出さないことを確かめるテストのダミーには、認証情報に見える名前(`token`、`key`、`secret`、`signature` など)のクエリやキーを使わず、`page` のような中立の名前を使う。
ダミーの ID は、12 桁の数字だけの並びにせず、英字を混ぜた、明らかに架空の形にする。

## 理由

認証情報に見える名前や、12 桁の数字(アカウント ID の形)は、ダミーでも本物と見分けがつかない。検査役が `WARN` で指摘し、判定が OK にならず、手戻りになる。
文脈で判断する検査なので、機械検査では先に止められない。

## 対処

テストのダミー(URL のクエリ名、ID、名前)を書くときに、上の形を避ける。例: クエリは `?page=2`、ID は `acct-ab12-test` のような形にする。
連結で組み立てる必要がある、機密の形のダミー(アクセスキーなど)は、別の注意書き(`0001-test-dummy-values-concat.md`)に従う。
