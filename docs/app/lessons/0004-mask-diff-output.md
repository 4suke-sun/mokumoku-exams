# デプロイ前の差分の出力は、環境変数の値を伏せてから扱う

## 注意すること

デプロイ前の差分の確認(`cdkd diff` など)は、リソースの設定を新旧そのまま表示する。Lambda の環境変数や CloudFront のオリジンのヘッダーに入れた合言葉の値も、そのまま出る。出力を、共有・記録・コミットする前に、値を伏せる。

## 理由

差分は、変更のあるプロパティの旧い値と新しい値を両方出す。合言葉やトークンのような機密の値が環境変数にあると、変更のたびに、画面、ログ、会話の記録へ現れる。

## 対処

- 差分は、値が出てもよい場所でだけ実行し、出力をそのまま貼らない。
- 確認に使うときは、`sed` などで、環境変数と識別子の値を置き換えてから読む(例: アカウント ID の 12 桁を `<acct>` に置き換える)。
- 機密の値を環境変数に入れる設計では、値が表示される場面を、手順書に書いておく。
