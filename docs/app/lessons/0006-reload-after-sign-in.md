# ログインの直後の画面の移動は、ページごと読み込み直す

## 注意すること

ログインの状態が変わった直後に画面を移るときは、`router.push` ではなく、ページごと読み込み直す(`window.location.assign`)。

## 理由

Next.js のクライアントの遷移は、リンクの先読みの結果を、しばらく使い回す。未ログインの画面(ログイン画面のヘッダーなど)にホームへのリンクがあると、先読みの結果は「ログイン画面への転送」になる。
ログインのあとに `router.push` でホームへ移ると、この結果が使われてログイン画面に戻り、ログインできたのかがわからなくなる。
単体テストでは `next/navigation` を差し替えるため、この問題は見つからない。本番のビルド(先読みが働く)でだけ起きる。

## 対処

- ログインやログアウトの直後の移動は、ページごと読み込み直す処理を、1 か所の関数(例: `lib/auth/navigate.ts`)にまとめて使う。
- 単体テストでは、その関数を差し替えて、移る先を確かめる。
