# ブラウザの自動操作では、画面が React の受け持ちになるまで待ってから押す

## 注意すること

E2E などでフォームの送信やボタンを押す前に、その部品が React の受け持ちになった(ハイドレーションが終わった)ことを待つ。
読み込み直後に押すと、操作が効かない、またはフォームがページごと送信される。

## 理由

サーバーが描いた HTML は、スクリプトの読み込みと実行が終わるまで、押しても何も起きない(`onClick` が付いていない)。
フォームは、`onSubmit` が付く前に押すと、ブラウザの既定の動き(同じ URL への送信)になり、入力が消えて画面が戻る。
開発サーバーは、画面を初めて開くときにビルドするため、この待ち時間が長く、ときどきだけ失敗する不安定なテストになる。

## 対処

- フォームは、`__reactProps` が付くまで待ってから入力・送信する(`page.waitForFunction`)。
- ボタンは、押した結果(`aria-pressed` や画面の変化)を確かめ、起きるまで押し直す(`expect(...).toPass()`)。
- 固定の待ち時間(`waitForTimeout`)は使わない。
