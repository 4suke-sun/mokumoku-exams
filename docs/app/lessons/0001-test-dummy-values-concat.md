# テストのダミー値は、文字列の連結で組み立てる

## 注意すること

機密情報の形をしたダミー値(アクセスキー、アカウント ID、ローカルのパスなど)を、テストにそのまま書かない。連結などで、実行時に組み立てる。

## 理由

そのまま書くと、機密検査が、テスト自身を違反として止める。テストファイルを検査の対象から外すと、ファイル名をテストの形にするだけで、検査を通れる抜けになる。

## 対処

値を分けて書き、実行時に結合する。たとえば、先頭の 2 文字と残りを別の文字列にして連結する。変数名にも、`secret` や `password` のような語を使わない(代入を見る検査に当たる)。検査にかける前に、テストファイルを検査して、指摘が 0 件であることを確かめる。
