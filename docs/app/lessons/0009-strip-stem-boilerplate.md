# 設問文の重複の比較では、共通の決まり文句を外してから比べる

## 注意すること

設問文どうしの類似度で重複を判定するときは、多くの設問に共通する末尾の決まり文句(「最も適切なものはどれですか。」
「2 つ選択してください。」など)を外してから比べる。

## 理由

文字の 2 つ組で比べる類似度は、共通の言い回しが長いほど高くなる。短い設問では、決まり文句が全体の半分近くを占め、
論点の違う設問どうしでも、保留のしきい値を超えることがある。しきい値を上げて避けると、言い換えただけの設問を見逃す。

## 対処

- 設問文は、末尾の決まり文句を外した部分で比べる(`packages/pipeline/src/draft/similarity.ts` の `stemSimilarity`)。
  外すと何も残らない設問は、元の文で比べる。
- しきい値を変える前に、公開済みの問題どうしの類似度の分布(上位の組の中身)を見て、高い組が本当に同じ論点かを確かめる。
- 決まり文句の形を増やしたら、言い換えただけの設問が重複の高さに残ることを、テストで確かめる。
