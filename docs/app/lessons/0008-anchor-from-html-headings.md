# 事実カードのアンカーは、HTML の見出しの要素から取る

## 注意すること

事実カードのアンカーの見出し(`anchor.heading`)は、HTML の見出しの要素(`<h1>`〜`<h6>`)の `id` 属性か、見出しの文から取る。
ページに埋め込まれたデータ(スクリプトの中の JSON など)にある識別子や節の番号は、見出しの `id` ではないので使わない。

## 理由

検査(根拠の照合)は、HTML の見出しの要素で本文を節に分け、アンカーに当たる節の中で引用と数値を確かめる。
本文を埋め込みのデータで持つページでは、データの側にも節の識別子があり、抽出がそれをアンカーに使うと、節が見つからず、
そのページのカードがすべて不採用(`anchor-not-found`)になる。見出しの文の中の文字参照(`&nbsp;` など)も、
文字に戻さずに比べると、一致しない。

## 対処

- 抽出の指示(`.claude/agents/fact-extractor.md`)に、見出しは HTML の見出しの要素だけを指し、埋め込みのデータの識別子を使わないことを書く。
- 見出しの文は、文字参照を文字に戻してから比べる(`packages/pipeline/src/text.ts` の `normalize`)。
- 1 つの出典のカードがまとめて `anchor-not-found` になったら、その出典の見出しの付け方を確かめ、抽出をやり直す
  ([事実カードの作法と運用手順](../../fact-cards.md)の「5.1 抽出をやり直すとき」)。
