# 開発サーバーが自動生成するファイルは、コミット前に中身と置き場を確認する

## 注意すること

開発サーバーやビルドツールは、設定ファイルや指示ファイルを自動で生成・追記することがある。初めて動かしたあとは、`git status` で新しいファイルを確認し、コミットするものと、無視するものを分ける。

## 理由

自動生成されたファイルが、プロジェクトの方針(置かないと決めたファイル、環境固有の値を含むファイルなど)に反していても、`git add` の対象に混ざる。ステージする範囲を広く指定すると、気づかずに履歴に載る。

## 対処

- ステージは、意図したパスを個別に指定する。
- 毎回生成されるファイルは、`.gitignore` に追加する。
- 動かす前後で `git status` を比べ、増えたファイルの用途を確認する。
