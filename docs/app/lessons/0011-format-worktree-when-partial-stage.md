# 部分的にステージするときは、作業ツリーの同じファイルも整形する

## 注意すること

ファイルの一部の変更だけをステージするときは、ステージしない変更を含めて、作業ツリーの同じファイルを整形してからコミットする。

## 理由

コミット前のフックの整形の検査は、ステージした差分ではなく、作業ツリーのファイルを読む。同じファイルに、別の未ステージの変更があると、その変更の整形の誤りで、ステージした側の内容が正しくても、コミットが止まる。

## 対処

部分的にステージする前に、対象のファイルだけを整形する(`npx biome check --write <ファイル>`)。`.githooks/pre-commit` のコメントにある `npm run format` は、リポジトリ全体を整形し、未ステージのほかのファイルも書き換えるので、部分的にステージするときは使わない。整形のあとで、ステージする範囲を選ぶ。止まったときは、未ステージの変更の側を整形してから、コミットし直す。
