# 0024. 試験ガイドの対象サービス・対象外サービスの一覧で、問題の範囲を検査する

- 状態: 採用
- 日付: 2026-10-27
- 補う ADR: 0018、0021

## 背景

試験ガイドは、対象のサービスと、対象外のサービスを示す。ADR 0018 は、対象サービスの一覧だけを台帳に持ち、出題計画と点数票の束(サービスの偏り)に使う。
対象外サービスの一覧は、抽出しない。問題が、対象外のサービスを問う、または一覧にないサービスを問うことを、機械で確かめる仕組みはない。
判定役(ADR 0021)の J5(範囲)は、一覧を渡されず、問題の本文と基準だけで判断する。

## 決定

- **対象外サービスの一覧を、台帳に持つ**(`guide.excludedServices`)。対象サービスの一覧(`guide.services`)と同じ形(名前だけ、1 件 80 文字以内、300 件まで)で、抽出役(`guide-extractor`)が抽出する。
  取り込みは、一覧の中で名前が重ならないこと、名前が本文に出ること、同じ名前が対象と対象外の両方にないこと(`service-overlap`)を確かめる。示さないときは持たない。
- **範囲の検査(機械)**を、`packages/pipeline/src/shared/scope.ts` に置く。設問文と選択肢の本文から、`shared/services.ts` の名前の照合(ADR 0018)で、サービスを見つけて分ける。
  - 対象外のサービスが、設問文か正答の選択肢に出る: 主題の逸脱。
  - 対象外のサービスが、誤答の選択肢にだけ出る: 誤答の作り方として自然な場合がある。
  - 対象にも対象外にもない、サービスらしい名前が出る: 一覧の抽出漏れか、新しい名前かを人が確かめる。サービスらしい名前は、「Amazon」「AWS」で始まる固有の表記だけを数える(文字列の一致による目安)。
- **置き場は 2 か所**。
  - 下書きの取り込み: 主題の逸脱は不採用にする(理由コード `scope:out-of-scope-subject`)。誤答のみ(`scope-out-of-scope-distractor`)と、一覧にない名前(`scope-unlisted-service`)は警告にとどめる。警告は場所(`questionText` か `choices`)だけを持ち、名前は持たない。
  - 公開済みの問題: 点数票(`score`)が、同じ検査を読み取りで流し、該当する問題の ID を報告する(点数と終了コードは変えない)。判定の候補として、人が見る。
- **判定役の J5 に、一覧を渡す**。依頼に、対象サービスと対象外サービスの一覧(`scope`)を載せる。機械の検査と判定役が同じ材料を見て、機械は名前の照合を、判定役は文脈(誤答として自然か、主題か)を担う。
  依頼の形が変わるので、依頼の版(`JUDGE_REQUEST_VERSION`)を上げる(依頼のキャッシュが切れる)。一覧がない試験は、`scope` を載せない(従来どおり)。
- 一覧は、試験ガイドから抽出した値で、誤りうる。機械の検査は、止めるのを主題の逸脱に絞り、残りは警告と人の確認にする。

## 却下した案

- 対象外のサービスが誤答に出るだけでも不採用にする: 誤答の作り方の幅(別の関心事への取り違えの型)を狭める。
- 一覧にない名前を不採用にする: 一覧の抽出漏れや新しい名前で、正しい問題を止める。
- 判定役にだけ任せて、機械の検査を置かない: 範囲外の出題の取りこぼしが、判定役の解釈に依る。

## 結果

- 台帳の形が増える(古い記録は、そのまま読める)。範囲の検査は、一覧がある試験だけで動く。
- 取り込みと点数票の 2 か所に、同じ検査の呼び出しがある。検査の本体は 1 か所(`shared/scope.ts`)。
