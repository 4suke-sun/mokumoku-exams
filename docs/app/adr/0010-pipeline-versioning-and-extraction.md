# 0010. pipeline の版はアプリと同じ版で運用し、切り出しは v1.0.0 以降に判断する

- 状態: 採用
- 日付: 2026-10-13

## 背景

pipeline は、アプリと同じリポジトリに置きます(ADR 0005)。版の付け方と、別のリポジトリへ切り出す条件を決めておきます。

## 決定

- pipeline は、アプリと**同じ版番号・同じタグ**で運用します。pipeline 専用の版は持ちません。
- 規約(1 版 1 PR、リリースノート、マイナーとパッチの基準)は、アプリと同じです。
- 別のリポジトリへの切り出しは、**v1.0.0 以降に、必要になったとき**に検討します。必要になった例は、
  他のリポジトリから使う要望が出たとき、作問の対象が増えて管理が重くなったときです。
- 切り出すときは、境界(ADR 0005)を守ってきたことが前提です。履歴の書き換えは、人の承認を待ちます。

## 理由

- 版を分けると、仕様の変更と pipeline の追従が別々に動き、食い違いを見つけにくくなります。
- 切り出しの必要は、使い始めてから分かります。先に決めても、前提が変わります。

## 採用しなかった選択肢

- pipeline 専用の版を持つ: 管理が増え、アプリとの対応が分かりにくくなります。
- 最初から別のリポジトリに分ける: ADR 0005 のとおり、管理が二重になります。
- 切り出しの条件を数値で決める: 現時点では根拠がなく、あとで見直す手間が増えます。

## 影響

- pipeline の変更も、リリースノートに載せます。
- 汎用化したくなっても、v1.0.0 までは同居のまま進めます。
