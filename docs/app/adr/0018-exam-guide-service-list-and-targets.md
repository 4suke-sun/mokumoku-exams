# 0018. 試験ガイドの対象サービスの一覧を事実として持ち、事実カードの選び方でサービスの目標に寄せる

- 状態: 採用
- 日付: 2026-10-25

## 背景

作問パイプラインの出題計画は、分野・難易度・種別の軸だけを持つ。事実カードの選び方も、サービスの軸を持たない。そのため、作った問題は一部のサービスに偏り、試験ガイドの対象なのに一度も出ないサービスが残りうる。

- 試験ガイドの取り込みは、分野・配点・出題範囲・本番の値を取り出す。対象サービスの一覧のページは、試験ガイドの続きのページ(`guidePages`)として台帳に入っているが、一覧を取り出して使う処理がない。
- 出典と権利の方針(`docs/source-policy.md` の 2 節)は、直接の引用を 1 件 30 文字以内、1 つの出典あたり合計 100 文字以内にする。サービスの名前を全部並べると、引用として数えれば、この合計を超える。
- 資格によって、サービスの見方は違う(サービスの使い方を問う資格、役割の使い分けを問う資格、判断が中心の資格)。

## 決定

- 試験ガイドの取り込みで、対象サービスの一覧(サービスの名前だけ)を取り出し、台帳の試験ガイドの記録(`guide.services`)に持つ。
- 一覧は、サービスの名前という事実の一覧として扱い、引用の上限の対象にしない。名前のほかの文は持たない。台帳のスキーマが、名前の長さ(80 文字以内)と文字、件数(300 件まで)を絞る。取り込みは、名前が試験ガイドか続きのページの本文にそのまま出ることを確かめる。
- 対象サービスの目標は、試験ごとの設定(`plan.overrides.<試験コード>.services`)に、各サービスが出る問題の数の下限(`minPerService`)と、1 つのサービスが出る問題の割合の上限(`maxShare`)として持つ。目標を持つのは、まず DVA だけにする(下限 2 問、割合の上限 15%)。同じ場所に、サービスが 2 つ以上出る問題の割合の下限(`minMultiServiceShare`。任意。DVA は 30%)を持ち、点数票の束のサービスの分布の警告に使う(点数には入れない)。
- 目標は、出題計画の項目を変えず、下書きの依頼で事実カードを選ぶ順に効かせる。下書きの根拠にされた回数の少ないカードを先に選ぶ順は保ったまま、回数が同じカードの間で、主張に下限に届かないサービスが出るカードを先に、出るサービスがすべて割合の上限を超えるカードを後ろにする。
- 問題にサービスが出るかは、設問文と選択肢にサービスの名前が出るかで数える(文字列の一致による目安)。数えるのは、公開済みの問題と、不採用でない本文のある下書き。
- plan は、目標と一覧がそろうとき、公開済みの問題で、下限に届かないサービスと割合の上限を超えるサービスを報告する。

## 理由

- サービスの名前は言い換えられない固有の表記で、並べても出典の文章の表現を写すことにならない。名前のほかの文を持たない形に絞れば、引用の上限の趣旨(本文の写しを持たない)と食い違わない。
- 一覧をコミットすれば、ほかの環境でも、同じ一覧で目標を測り、同じ選び方を再現できる。
- 出題計画にサービスの軸を足すと、計画の項目の ID と下書きの依頼の鍵が、すべての資格で変わる。事実カードの選び方で寄せる形なら、目標を持たない資格の依頼は変わらない。
- 下限と割合の上限は、サービスごとの細かな配分を決めずに、「一度も出ない」と「一部に集まりすぎる」の 2 つの偏りを直接扱える。

## 採用しなかった選択肢

- 一覧をコミットせず、作業用の置き場にだけ置き、目標の数だけをコミットする: ほかの環境で一覧を再現するには、取得と抽出をやり直す必要がある。測り方も、環境ごとにずれうる。
- 出題計画にサービスの軸を足し、項目をサービスごとに分ける: すべての資格の計画の項目と依頼の鍵が変わる。分野の配点とサービスの配分の二重の配分を決める必要があり、項目の数も大きく増える。
- サービスごとの問題数の目標を、出題範囲の項目から比例で決める: 出題範囲の言い換えにサービスの名前が出るとは限らず、比例の根拠が弱い。
- すべての資格に目標を持たせる: 資格によってサービスの見方が違う。まず DVA で効果を見てから、ほかの資格へ広げるかを決める。

## 影響

- 試験ガイドの抽出役の定義が変わるので、次の収集で、試験ガイドの抽出の依頼が出し直される。取り込むまで、台帳に一覧はなく、目標は効かない(plan が、取り込み直しを促す)。
- 目標を持つ資格では、事実カードを選ぶ順が変わるので、下書きの依頼の鍵が変わりうる。
- 一覧は、点数票の束の項目(サービスの偏り、複数のサービスにまたがる設問の割合)の測定にも使える。
