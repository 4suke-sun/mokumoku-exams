# AWS の資格に共通の書き方

AWS の資格の問題に共通する、文章の構成の特徴です。資格ごとの値は、[Cloud Practitioner](./aws-clf.md)・[Developer - Associate](./aws-dva.md)・[AI Business Strategist](./aws-aib.md) にあります。
採点は [点数票](./scorecard.md) です。

## 1. 設問の構成

設問は、次の 2 つの部品でできています。

1. **状況**(任意): 誰が(ある企業・あなた・チーム)、何をしようとしているか、どんな要件があるかを書きます。
2. **問い**(必須): 状況の要件を満たすものを、1 文で問います。

| 部品 | 決まり |
| --- | --- |
| 状況 | 1 文目で主体と目的・現状を書き、次の文以降で要件・制約を示す(「〜する必要があります」「〜が求められています」)。文の数は資格別 |
| 問い | 状況とは別の 1 文。末尾は問いの形(です・ます)で終える。資格によっては、状況と別の段落にする |
| 主体 | 状況の書き出しは「ある企業は」が主。ほかに「あなたは」「ある会社は」「あなたの会社は」「A 社は」「ある開発者は」「あるデベロッパーが」。事実を直接問う設問は、サービス名や概念を主語にしてよい |
| 1 文 1 要件 | 要件・制約は、1 文に 1 つ。並べるときは文を分ける |
| 根拠 | 正答を決める要件・制約は、出典と事実カードで根拠を示せるものにする |

## 2. 問いの形

- 末尾は「どれでしょうか」「どれですか」「何でしょうか」「何ですか」か、「〜を選択してください」で終えます。句点の有無は問いません。
- 「どれか。」のように、「です・ます」を含まない末尾は避けます(点数票で減点します)。
- サービスを問うときは「どの AWS サービス(または機能)を〜」の形を使ってよい。
- 複数選択は、選ぶ数(「2 つ選択」)を書き、正答の数と一致させます。2 つが主で、3 つはまれです。
- 否定の設問(〜でないもの、〜サポートされていないもの)は、まれです。使うなら否定の語を 1 つだけにします。

## 3. 選択肢

| 項目 | 決まり |
| --- | --- |
| 数 | 単一選択は 4。複数選択は 5(2 つが主) |
| 長さ | 最長÷最短は 4 倍以内(資格別の値がある)。選択肢の長さそのものは資格別 |
| 形 | 1 問の中で、形(サービス名だけ/語句/文)と句点の有無をそろえる。どの形が主かは資格別 |
| 並べ方 | 正答の位置と長さに偏りを作らない。正答だけが際立って長い(短い)形にしない |
| 誤答 | 正答と同じ分類のものから選ぶ。サービスを問う設問では、似たサービス・近い機能・よくある誤解。やり方を問う設問では、正答の部品を 1 つ入れ替えたもの。分類の違うものは混ぜない |
| 一括り | 「すべて正しい」「いずれでもない」は置かない |

## 4. 要件と制約の言い回し

状況の要件を示す、短い定型句です。

| 種類 | 言い回しの例 |
| --- | --- |
| 必要性 | 〜する必要があります/〜が求められています |
| 目的 | 〜したいと考えています/〜を予定しています |
| 照合 | この要件を満たす〜 |
| コスト | 最もコスト効率が高い/費用対効果が高い/コストを削減する |
| 運用 | 運用上のオーバーヘッドを最小限に/できる限り |
| セキュリティ・可用性 | 暗号化・アクセス制御/障害への耐性 |
| 数値 | 台数・容量・期間・金額 |

- 数値は、**答えを分けるときだけ**書きます。飾りで入れません。
- 形容詞だけの制約(「安全に」「効率よく」)は、答えを分けないので避けます。

## 5. 解説

問題文の書き方とは別に、解説の傾向です。既存の規則(`explanation-*`)と重ならない部分だけを書きます。

- 構成は、正答の節、誤答ごとの節(選択肢の数−1)、末尾の参照です。
- 誤答の節は、その選択肢が何のサービス・概念かを述べたうえで、この設問の要件に合わないことを示します。
- 長さは資格別です。

## 6. 資格で違うもの

| 項目 | Cloud Practitioner | Developer - Associate |
| --- | --- | --- |
| 設問文の長さ | 短い(35〜125 字) | 長い(150〜360 字) |
| 状況の文の数 | 0〜2 | 2〜6 |
| 段落 | 1〜2 | 状況の段落と問いの段落に分ける |
| 選択肢の形 | サービス名が中心 | 手順や設定を述べる文 |
| 選択肢どうしの似かた | 似ていない | 並行する(1 要素だけ違う) |
| 解説の長さ | 短め | 長い(手順・設定の箇条書きを伴う) |

サービスを選ぶ資格は設問が短く、やり方を選ぶ資格は設問が長くなります。長さの帯は、資格ごとに持ちます。
