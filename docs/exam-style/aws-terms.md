# AWS の用語の辞書

AWS の問題の、訳語と略語の書き方の決まりです。作問役と書き直し役が指針として読み、判定の基準(使う語と使わない語の対)と、取り込みの検査(`avoid-term`・`abbr-first-use`。[作問のスタイルガイド](../question-style.md))が同じ表を使います。表が定義元で、ほかの場所に写しません。
表の形が決まっています(`packages/pipeline/src/shared/terms.ts`)。形が違うと、取り込みが「用語の辞書の誤り」で止まります。

## 使う訳語と使わない訳語

| 使う語 | 使わない語 | 対象外の語 | 条件 |
| --- | --- | --- | --- |

使わない訳語は、まだ決めていません。決めたものを、この表に足します。

## 略語と正式名称

次の略語は、1 問の中の最初の出現に、「略語(正式名称)」の形で正式名称を補います(半角の括弧で、略語との間に空白を置きません)。2 回目以降は補いません。

| 略語 | 正式名称 |
| --- | --- |
| SQS | Amazon Simple Queue Service |
