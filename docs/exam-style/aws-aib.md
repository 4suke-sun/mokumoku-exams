# AWS Certified AI Business Strategist(AWS-AIB-C01)の書き方

[AWS の資格に共通の書き方](./aws-common.md)に加わる、この資格の値と言い回しです。採点は [点数票](./scorecard.md) です。

## 1. 要点

**設問は中くらいの長さで、技術の細部よりも、導入・ガバナンス・責任ある AI・データの質・コスト・組織の進め方といった意思決定を問います。** 単一選択だけで、選択肢は短い文が並行し、長さがそろいます。Cloud Practitioner と Developer - Associate の値は流用できません。

| 項目 | 目安 |
| --- | --- |
| 設問文の文字数(複数選択の表記を除く) | 120〜300(満点)、90〜360(部分点) |
| 状況の文(問いより前の文)の数 | 2〜6 |
| 設問文の段落 | 状況の段落と、問いの段落を分ける。問いの段落は 100 字以内 |
| 状況つきの設問の割合(束) | 90% 以上(状況の文が 2 文以上あるもの) |
| 最長の選択肢の文字数 | 100 以内(満点)、140 以内(部分点) |
| 選択肢の最長÷最短 | 2.5 倍以内(満点)、3.5 倍以内(部分点) |
| 選択肢どうしの類似度(バイグラムの Dice) | 0.85 未満 |
| 複数選択の割合(束) | 0% 以下(複数選択は置かない) |
| 設問文の中央値(束) | 160〜240 字。90 パーセンタイルは 300 字以下 |
| 選択肢の形(束) | 文が 80% 以上 |
| 設問文の先頭 8 文字が同じものの割合(束) | 45% 以下 |

## 2. 設問の構成

```text
[状況の段落]  主体・現状 → 課題や数値 → 目標・要件(2〜6 文)
[問いの段落]  これらの要件を満たすのはどれですか。/最も適切なのはどれですか。(1 文)
```

- 主体は「ある〜企業(会社・銀行・組織・団体・機関・法人・メーカーなど)は」が主です。「ある企業は」でもよい。業種や規模の語を挟んでよい。ほかに「あなたは」。社名の形(「A 社は」)や、開発者を主役にした形は使いません。
- 状況は、**現状の取り組み**(導入した AI、チームの体制、データの状態)から始め、課題や数値に進み、「同社は〜したいと考えています」「〜する必要があります」で要件を示します。
- 問いは「これらの要件を満たすのはどれですか」「最も適切な対応はどれですか」「最初に実施すべきステップはどれですか」「最も可能性が高い原因は何ですか」が主です。
- 否定の設問は使いません。
- 問いの末尾は、すべて「です・ます」(「〜ですか」「〜どれですか」)です。

## 3. 選択肢

| 項目 | 決まり |
| --- | --- |
| 数 | 4(単一選択だけ) |
| 形 | **短い文**。「〜する。」で終える(句点あり)。1 問の中でそろえる。複数の短文を並べた選択肢も使ってよい |
| 内容 | 取り組み・対応・方針を述べる文。技術の設定値よりも、順序・範囲・タイミング・責任の所在といった意思決定の違い |
| 並行 | 選択肢どうしは、同じ種類の取り組みで、**1 点**(順序・範囲・タイミング・責任の所在)だけ違う |
| 長さ | 最長÷最短は 2.5 倍以内。そろえる |
| 偏り | 正答の位置と長さに偏りを作らない |

## 4. 作問の指示に落とすとき

1. 設問文は **状況の段落+問いの段落**(空行で分ける)。状況 2〜6 文、120〜300 字。
2. 選択肢は短い文にして句点で終える。最長の選択肢は 100 字以内にする。単一選択だけで書く。
3. 誤答は、正答と同じ種類の取り組みで、順序・範囲・タイミング・責任の所在のどれか 1 点をずらして作る。事実カードの主張で誤りを示せるものにする。
4. 状況の要件・制約は、事実カードで根拠を示せるものだけにする。長くするために、根拠のない要件を足さない。
5. 難易度との対応は拘束しない。意思決定を問う設問が中心なので、`easy` も状況つきで書くのが自然。
6. 問いは「です・ます」で書く。選択肢の「〜する。」は常体のままにする。

## 5. 範囲の注意

- 設問は、サービスの設定や API よりも、**AI を導入・運用・統治する側の判断**を問います。
- 解説は、正答の理由と、各誤答がずれている点を述べます。
