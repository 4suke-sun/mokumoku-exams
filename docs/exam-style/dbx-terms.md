# Databricks の用語の辞書

Databricks の問題の、訳語と略語の書き方の決まりです。作問役と書き直し役が指針として読み、判定の基準(使う語と使わない語の対)と、取り込みの検査(`avoid-term`・`abbr-first-use`。[作問のスタイルガイド](../question-style.md))が同じ表を使います。表が定義元で、ほかの場所に写しません。
表の形が決まっています(`packages/pipeline/src/shared/terms.ts`)。形が違うと、取り込みが「用語の辞書の誤り」で止まります。

使う語は、公式の日本語のドキュメントの訳語です。使わない語は、その別の訳です。対象外の語は、使わない語を含むが、別の意味の語で、検査の前に除きます。「条件」の列は、人が読む注記です。取り込みの規則は、条件を見ずに、使わない語を場所によらず止めます。判定の基準には、注記として載ります。

表は、公式の日本語のドキュメントの訳語の対応表(14 行)を、使う語ごとに分けた 16 行です。
