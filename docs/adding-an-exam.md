# 資格を追加する手順

新しい資格を、問題集に加える手順です。データの形と検査の規則は [問題データの仕様](./data-spec.md) が正本で、この文書は、その順番と置き場所をまとめます。
アプリのコードは変えません(資格マスタと `data/` のファイルだけで、一覧・モード選択・出題・結果の画面ができます)。

## 1. 決めること

| 項目 | 決め方 |
| --- | --- |
| 資格コード(`examCode`) | 英大文字で始まる英大文字と数字(2〜16 文字)。ほかの資格と重ならないもの。ファイル名と URL(`/exams/<資格コード>`)に使います |
| 公開の状態(`status`) | 問題がそろうまでは `coming-soon`(一覧に「近日公開」と出すだけ)。出題できるようになったら `published` |
| 分野(`domains`) | `domain1`〜`domainN` のコードと表示名、公式の配点の重み(合計 1) |
| 本番モードの値 | `officialQuestionCount`(出題数)と `officialTimeMinutes`(制限時間の分)。公式の試験に合わせます |

## 2. ファイルの命名と配置

すべて、リポジトリ直下の `data/` に置きます。`<コード>` は、資格コードを英小文字にしたものです(例: 資格コード `SAMPLE` なら `sample`)。

| ファイル | 内容 | 必要なとき |
| --- | --- | --- |
| `data/exams.json` | 資格マスタ。資格ごとに 1 件を足します | 常に |
| `data/questions.<コード>.json` | 問題 | `published` のとき必須。`coming-soon` のときは置きません |
| `data/curriculum.<コード>.json` | 学習モードの単元と本文 | 任意。ないと、学習モードは「準備中です」になります |

- ファイル名のコードと、ファイルの中の `examCode` は一致させます。
- 問題の ID は `<資格コード>-<4 桁の連番>`(例: `SAMPLE-0001`)です。一度使った番号は、問題を消しても再利用しません。

## 3. 手順

1. **近日公開として載せる**(任意)。`data/exams.json` の `exams` に、`examCode`・`status: "coming-soon"`・`vendor`・`name`・`shortName`(と任意の `note`)だけの 1 件を足します。
2. **問題を書く**。`data/questions.<コード>.json` を作り、[問題データの仕様](./data-spec.md) の「3. 問題」の形で書きます。
   選択式(択一・複数選択)の問題数は、本番モードの出題数(`officialQuestionCount`)以上にします(自由記述は数えません)。
3. **公開にする**。資格マスタの 1 件を `status: "published"` にし、`edition`・`category`・`passingScore`・`totalScore`・
   `officialQuestionCount`・`officialTimeMinutes`・`domains` を足します。
4. **カリキュラムを書く**(任意)。`data/curriculum.<コード>.json` を、仕様の「11. カリキュラムのデータ」の形で作ります。
5. **検査する**。次の「4. 検査」を通します。
6. **画面で確かめる**。`npm run dev` で、資格の一覧、モード選択、通常出題と本番モード、結果の画面を開きます。
7. **リリースノートに書く**。`data/release-notes.json` の、その版のエントリに、加えた資格を書きます。

## 4. 検査

```sh
npm run validate:data   # 資格マスタ・問題・カリキュラム・使い方ページの検査
npm run build           # 公開中の資格のページが、ファイルから作れること
npm test
```

`validate:data` は、次のような食い違いを見つけます(規則の一覧は、仕様の「4. 機械検査する規則」)。

- 公開中の資格に問題のファイルがない。資格マスタにない資格の問題やカリキュラムがある
- ファイル名のコードと、中の `examCode` が違う
- 問題の分野のコードが、資格マスタの分野にない
- 選択式の問題数が、本番モードの出題数より少ない
- 問題の ID の重複、接頭辞の誤り、正解のキーの誤り

報告には、ファイル名・項目の位置・問題の ID と規則の種類だけが出ます(本文は出ません)。

## 5. 注意

- 実データの扱いは、加えるときに、そのつど決めます(仕様の「9. サンプルデータ」)。
- 資格マスタの値(合格点、問題数、制限時間、分野の重み)を変えたときも、同じ検査を通します。
