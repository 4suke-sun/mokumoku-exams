# 人の判断の記録

作問パイプラインの各段階で、人が確かめた結果を残す記録です。記録はコミットし、収集・事実カード・下書きが読みます。

## 1. 置き場と形

資格ごとに 1 つの JSON を、`packages/pipeline/decisions/<コード>.json` に置きます(設定 `decisionsDir`)。人の確認を抜き取りにしたときは、同じ場所に抜き取りの記録も置かれます(「4」)。読み込むたびにスキーマで検査し、
未知の項目、理由コードの形に合わない値、同じ対象への 2 件目の判断は、読み込みで落ちます(`判断の記録の誤り`)。

```json
{
  "examCode": "<資格コード>",
  "decisions": [
    { "target": "source", "url": "https://example.com/guide.html", "contentHash": "<本文のハッシュ>", "decision": "accept", "reason": "stale-but-correct" },
    { "target": "fact", "id": "f-<12 桁>", "decision": "release", "reason": "not-a-conflict" },
    { "target": "draft", "id": "d-<12 桁>", "decision": "approve", "reason": "reviewed" }
  ]
}
```

| 対象 | 判断 | 効き方 |
| --- | --- | --- |
| `source`(出典。URL と本文のハッシュで指す) | `accept` | 日付が古い(`stale`)だけで止まった出典を、根拠に使える状態(`active`)にする。記録した本文のハッシュと同じ間だけ効き、本文が変わると再び止まる |
| `fact`(事実カード。ID で指す) | `release` | 矛盾の保留(`conflict`)を解く。次の取り込みでも保留に戻らない |
| `fact` | `reject` | 不採用にする(理由コード `human-rejected`)。同じ内容を再抽出しても、不採用のまま |
| `draft`(下書き。ID で指す) | `release` | 保留(`ambiguous:*`・`review:*`)を解いて、通過にする |
| `draft` | `approve` | 承認を記録する(確認済みに数える)。保留の下書きなら、保留も解く |
| `draft` | `reject` | 不採用にする(理由コード `human-rejected`)。本文は持たない |

- 理由は自由な文ではなく、理由コード(英小文字・数字・ハイフン、48 文字まで)で書きます。本文や個人の情報を入れません。
- 誰が判断したかは持ちません。氏名・メールアドレス・表示名などを持つ項目はありません。
- 事実カードの矛盾(2 件の組)の保留は、カード 1 件ずつの判断で解きます。組の両方を解くときは、2 件書きます。

## 2. 書き方

記録は、確認用の表と判断のシートから取り込むか(下書き。`draft <試験コード> --review` と `--decide`。[出題計画と下書きの手順](./drafting.md))、ファイルを直接直して書きます。どちらの場合も、次に各段階を実行したときに反映されます。

- 事実カード: `facts <試験コード> --import`(依頼がなくても、判断を反映します)
- 下書き: `draft <試験コード>`(どのモードでも、読み込んだときに反映します)
- 出典: `collect <試験コード>`

## 3. 判断の引き継ぎと、対象がなくなった判断

事実カードの ID と下書きの ID は、内容から決まります。同じ内容を作り直すと同じ ID になり、判断が引き継がれます。内容が変わると別の ID になり、
判断は引き継がれません。対象がなくなった判断(カードが消えた、下書きが作り直されて ID が変わった、出典の本文が変わった)は、
黙って捨てずに `判断の対象なし: <種類> <ID または URL>` を報告します。報告された判断は、新しい対象を確かめ直して書き直すか、消します。

## 4. 抜き取りの記録

人の確認を抜き取りにしたとき、判断の記録のそばに `<コード>.sampling.json` が置かれます。率・種・確認する下書きと事実カードの ID、確認しないものの ID、全件の確認へ戻した理由を持ちます(本文は含みません)。手では書き換えません。決まりは[問題を作る手順書](./question-production.md)の「8.1 抜き取りで確認する」です。
